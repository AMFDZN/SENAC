Rotina Diária de Trabalho (Para Evitar Conflitos)
Sempre usar este fluxo para alternar entre a máquina da escola e a de casa sem sobreposição de código:

iniciando (no Pop!_OS ou Windows):


git pull origin dev

Ao finalizar as alterações:

git add .
git commit -m "alterações de hoje"
git push origin dev

5. Arquivo .gitignore Recomendado

Crie um arquivo chamado .gitignore na raiz da pasta [SENAC] para impedir o envio de arquivos temporários do VS Code ou do sistema operacional:

# VS Code
.vscode/

# Node / Dependências (se aplicável)
